# 报告类型与结构选择

只读取与当前任务有关的部分。结构服务于研究问题，不要求每份报告机械包含全部章节。

## 问卷与统计报告

常用结构为标题、摘要与关键词、引言、研究设计与样本、结果、讨论、结论与建议、参考文献和附录。

交代调查对象、实施时间、发放与回收、有效样本、抽样方式、清洗规则、变量和分析方法。先写描述统计，再写差异、相关或模型结果。显著性不等于影响很大，还应说明效应大小和现实含义。表格承载精确数值，图形展示趋势和比较，正文解释最重要的发现。

## 访谈、焦点小组与田野报告

常用结构为标题、摘要与关键词、研究问题、场域与参与者、资料收集和分析、主题发现、讨论、结论、伦理说明和附录。

说明对象如何选择、访谈时间和地点、是否录音、如何转写和编码。主题应来自多份材料中反复出现的经验或矛盾。每个主题写清表现、代表性材料、解释和反例。少数人的意见不能写成全体共识。

## 案例与政策报告

常用结构为问题与背景、案例选择、资料与方法、过程或机制、主要发现、条件与限制、对策建议和参考文献。

说明案例为何被选择，它是典型、极端、关键还是用于比较。区分政策文本规定、执行过程、参与者评价和作者判断。建议要对应材料揭示的问题及现实执行条件。

## 文本、作品与史料研究

常用结构为引言、研究述评与问题、材料范围和版本、分析章节、结论、参考文献和必要的史料附录。

确定文本、版本、年代、作者立场和来源层级。后来的回忆不能直接当成事件发生时的原始记录。理论用于解释材料，不能替代细读。区分作品叙述、历史事实和研究者解释。

## 社会实践调研报告

常用结构为标题、摘要与关键词、实践缘起与研究问题、材料和方法、调查发现、实践行动及其依据、实际反馈与成果、反思与改进、结语、参考文献和附录。

调查发现说明为什么选择某类行动，实践记录说明行动如何发生，反馈材料说明实际效果。活动数量本身不是论证，应说明活动与研究问题的关系。反思写方法和结论的边界，不写琐碎失误清单，也不把普通问题包装成深刻经验。

## 混合材料报告

不要把问卷、访谈和案例各写一章后简单相加。围绕同一研究问题整合：问卷说明现象的分布或差异，访谈解释差异如何形成，案例、政策或文本展示机制在具体情境中的表现。材料冲突时保留冲突，分析口径、时间和对象差异，不强行统一。

## 摘要与结语

摘要通常写研究问题、材料与方法、核心发现和结论或建议，不写背景口号和成就介绍。

结语回应开头的问题，说明最可靠的发现、适用边界和可以继续推进的方向。结尾可以提升认识，但必须由前文证据自然推出，不能突然转成宣传口号。
